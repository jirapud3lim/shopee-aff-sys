# Affiliate Automation SaaS — Claude Code Documentation Starter

Use this kit at the root of an existing/new Git repository.

**Start here:** `CLAUDE.md` → `docs/agent/CURRENT_PHASE.md` → `docs/phases/PHASE_00.md` → `docs/agent/START_PHASE_00_PROMPT.md`.

- `CLAUDE.md`: always-on concise coding instructions.
- `docs/phases/PHASE_00.md` … `PHASE_08.md`: independent phase specs and checklists.
- `docs/agent/`: current work context, prompt and handoff.
- `docs/product/`, `docs/api/`, `docs/architecture/`: initial drafts for Phase 0.
- `docs/ROADMAP.md`: full original master roadmap (reference, not every-session context).

No application source code has been implemented in this kit. No platform API access has been verified.
