# Master Prompt เสียงพากย์ Storytelling

## ค่าที่ใช้สร้างเสียง

| รายการ | ค่าที่ใช้ใน EP.1 |
| --- | --- |
| โมเดล | Kokoro Thai `kunato/wayu-kokoro-thai-v1` |
| เสียง | ผู้หญิงไทย `f_mid_clear` (Voice ID `4`) |
| ความเร็วตอนสังเคราะห์ | `0.82` |
| ไฟล์เสียงต้นฉบับ | WAV โมโน 24 kHz แยกตาม Shot ID |

ใช้พรีเซ็ตและความเร็วนี้กับทุกตอนของ Storytelling รวมถึง Shorts และงานแก้เสียง เทียบโทนและจังหวะกับวิดีโอ EP.1 ฉบับที่ผู้ใช้อนุมัติ ไฟล์อ้างอิงในเครื่องอยู่ที่ `output/imagegen/ep01-female-voiceover/EP.1-documentary-female-thai.mp4`

## คำกำกับการเล่า

> เล่าด้วยเสียงผู้หญิงไทยโทนสารคดีแบบ EP.1 น้ำเสียงนิ่งและชัด ใช้จังหวะสม่ำเสมอแบบคนเล่าเรื่อง เว้นช่วงสั้นตามวรรคและก่อนเผยข้อมูลสำคัญ เน้นคำหลัก ชื่อสถานที่ และตัวเลขอย่างพอดี ให้ความตึงเครียดมาจากจังหวะและเนื้อเรื่อง คงน้ำเสียงและจังหวะให้ต่อเนื่องจากช็อตก่อนหน้า อ่านตามบทพากย์ที่อนุมัติ

ใช้คำกำกับนี้ตอนจัดวรรคของบทและตรวจเสียง ป้อนเฉพาะบทพากย์ที่ต้องการให้อ่านเข้า Kokoro Thai บันทึกเป็น `<Shot ID>.wav` แล้วตรวจคำพูด การออกเสียง จังหวะ และความยาวก่อนเจนวิดีโอ นำเสียงที่ตรวจแล้วไปวางบนภาพในขั้นตัดต่อ
